# SPEC — Телесуфлёр «speech»

## Цель
Минималистичный веб-телесуфлёр для iPhone 13, который вставляется в физический суфлёр-стекло перед камерой. Экран отражается на стекле, оператор смотрит в камеру и читает отражённый текст.

## Целевое устройство
- iPhone 13 в горизонтальной (ландшафтной) ориентации
- Safari iOS 14.5+
- Должно работать и на других современных iPhone, но iPhone 13 — основной

## Платформа и технологии
- **PWA** (Progressive Web App)
- Стек: **Vanilla JavaScript** (ES modules) + **Vite** + **CSS**
- Хранение: **IndexedDB**
- Распознавание речи: **Web Speech API** (бесплатно, встроено в Safari)
- Хостинг: **GitHub Pages**
- Установка на телефон: «Добавить на экран Домой» в Safari

## Функциональные требования

### Управление прокруткой
- **Авто-прокрутка** с регулировкой скорости — основной режим
- **Ручная прокрутка** свайпом пальцем
- **Голосовое следование** через Web Speech API (русский язык, fuzzy matching распознанных слов с текстом скрипта)

Все три способа могут работать совместно.

### Управление текстами (Библиотека)
- Локальное хранилище скриптов в IndexedDB
- Создание, редактирование, удаление, дублирование скрипта
- Без облака, без аккаунтов, без регистрации

### Режим чтения (Prompter)
- Полноэкранный режим (Fullscreen API)
- Landscape lock через Screen Orientation API
- Wake Lock — экран не уснёт во время чтения
- **Зеркальное отражение** по горизонтали (для суфлёра-стекла) — переключатель
- Опционально вертикальное отражение (для нестандартных конструкций)
- **Маркер-линия чтения** по центру экрана (тонкая, оранжево-жёлтая) — переключатель
- Минимум UI — только текст и редкие полупрозрачные контролы

### Настройки скрипта
- Размер шрифта (диапазон 24–128 px, default 64 px) — регулируется и в редакторе (слайдер), и в режиме чтения (кнопки A+ / A−); изменения в режиме чтения сохраняются в скрипт
- Скорость авто-прокрутки (1–100, default 30) — регулируется и в редакторе, и на лету в режиме чтения
- Межстрочный интервал
- Зеркало по горизонтали (вкл/выкл)
- Зеркало по вертикали (вкл/выкл)
- Линия чтения (вкл/выкл)
- Голосовое следование (вкл/выкл)

## Дизайн

### Принципы
- Минимализм, ничего лишнего
- Высокий контраст (важно для отражения через стекло)
- Крупные тач-цели (≥ 44×44 px)
- В режиме чтения — никакой анимации, кроме самой прокрутки

### Цветовая палитра
| Токен | Значение | Назначение |
|---|---|---|
| `--color-bg` | `#000000` | Фон (OLED-дружественный, минимум блика) |
| `--color-fg` | `#FFFFFF` | Основной текст |
| `--color-fg-dim` | `#888888` | Вторичный текст, метки |
| `--color-fg-faint` | `#444444` | Подсказки, разделители |
| `--color-accent` | `#FFB800` | Акцент: маркер чтения, активные элементы |
| `--color-danger` | `#FF4444` | Опасные действия (удаление) |
| `--color-surface` | `#0A0A0A` | Лёгкая высота над фоном |
| `--color-border` | `#1F1F1F` | Бордеры |

### Типографика
- Системный шрифт: `-apple-system, BlinkMacSystemFont, "SF Pro Display", system-ui`
- Текст в редакторе: 16–18 px
- Текст в суфлёре: 64 px (default), 24–128 px (диапазон)
- Вес шрифта в суфлёре: 600 (semibold) — лучшая читаемость с расстояния
- Высота строки: 1.5

## Нефункциональные требования
- Работает оффлайн после первой загрузки (Service Worker)
- 100% бесплатное использование — никаких подписок, API-ключей, оплат
- Приватность: все данные хранятся на устройстве, ничего не уходит на сервер

## Не входит в MVP (потенциальное v2)
- Запись видео во время чтения
- Облачная синхронизация скриптов
- Множественные пользователи
- Другие языки распознавания (только ru-RU)
- Bluetooth-пульты и педали
- Импорт/экспорт скриптов из файлов

## Поток пользователя
1. Открывает PWA в Safari → один раз добавляет на главный экран
2. Запускает иконку → попадает на экран **Библиотека**
3. Создаёт новый скрипт или открывает существующий → экран **Редактор**
4. Жмёт «Старт» → экран **Суфлёр** в полноэкранном режиме
5. (опционально) включает голосовое следование, разрешает микрофон
6. Читает текст, прокрутка идёт автоматически + следит за голосом
7. По окончании — выход в Библиотеку
