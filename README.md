## Зачем

Телесуфлёры в App Store либо платные, либо завалены рекламой и ненужными фичами. А мне как блогеру хотелось одного: открыл, вставил текст, поставил телефон в стекло суфлёра — и читаю. Чтобы текст ехал сам, а ещё лучше — следовал за моей речью.

Получилось вот это.

## Что умеет

- 🎙 **Голос ведёт текст** — Web Speech API распознаёт речь и подсвечивает текущее слово. Сбились — вернитесь, текст подхватит и сам перепрыгнет назад.
- ✋ **Авто-скролл руками** — без микрофона. Тап слева/справа — медленнее/быстрее.
- 🗣 **Голосовые команды** — «суфлёр стоп», «суфлёр старт», «суфлёр сначала», «суфлёр больше/меньше».
- 🪞 **Зеркало** — для стекла суфлёра перед камерой.
- 💾 **Полностью оффлайн** — IndexedDB + Service Worker. Добавляется на главный экран iPhone и работает без интернета.
- 📤 **Бэкап** — экспорт и импорт всей библиотеки в JSON.
- 🌗 **Тёмная и светлая темы**, перекалибровка темпа речи (wpm), память места остановки в каждом скрипте.

## Как пользоваться

1. **Откройте** [приложение](https://emorozoff.github.io/speech/) в Safari на iPhone.
2. **Добавьте на главный экран**: `Поделиться → На экран «Домой»`. Полноэкранный режим без панели браузера.
3. **Вставьте текст** скрипта, поставьте телефон в стекло суфлёра перед камерой, разрешите микрофон — и читайте.

Подробная памятка с командами и жестами — внутри приложения, в меню `⋯ → Памятка`.

## Стек

Vanilla JS · Vite · Workbox PWA · IndexedDB · Web Speech API · Wake Lock · Fullscreen.
**Ноль runtime-зависимостей.** Только то, что есть в браузере.

## Локально

```bash
npm install
npm run dev      # dev-сервер на http://localhost:5173
npm test         # 120 unit-тестов на встроенном node:test
npm run build    # production-сборка в dist/
```

Для тестов микрофона на iPhone нужен HTTPS — поднимайте `npm run dev -- --host` через `ngrok` или `localtunnel`, либо тестируйте уже задеплоенный URL.

Иконки и og-image баннер пересобираются скриптами:

```bash
node scripts/generate-icons.mjs       # 192/512/maskable/180-apple
node scripts/generate-og-image.mjs    # 1200×630 для шеринга
```
