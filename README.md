# speech

Минималистичный веб-телесуфлёр для iPhone 13. Открывается в Safari, добавляется на главный экран — и работает как нативное приложение в физическом суфлёре-стекле.

## Особенности
- Авто-прокрутка с регулировкой скорости
- Ручная прокрутка свайпом
- Голосовое следование за чтением (Web Speech API, русский)
- Зеркальное отражение текста для суфлёр-стекла
- Линия-маркер чтения
- Локальная библиотека скриптов (IndexedDB)
- Работает оффлайн (PWA)
- Полностью бесплатно — никаких подписок и API-ключей

## Стек
- Vanilla JavaScript (ES modules) + Vite
- CSS-переменные для дизайн-системы
- Web Speech API, IndexedDB, Wake Lock API, Screen Orientation API, Fullscreen API

## Локальная разработка

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173/`. Для тестирования на iPhone — откройте тот же адрес с iPhone в той же Wi-Fi сети (например `http://192.168.x.x:5173/`). Для Web Speech API нужен HTTPS — для тестов с микрофоном используйте `npm run dev -- --host` и [`localtunnel`](https://localtunnel.github.io/) или [`ngrok`](https://ngrok.com/).

## Сборка

```bash
npm run build
npm run preview
```

## Установка на iPhone

После деплоя:
1. Откройте URL приложения в **Safari** на iPhone
2. Тапните иконку «Поделиться» (квадрат со стрелкой)
3. Выберите «На экран Домой»
4. Готово — приложение запускается с иконки в полноэкранном режиме
